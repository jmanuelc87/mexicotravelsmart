# PRIVACY POLICY

**MÉXICO TRAVELSMART.MX ASSISTANT**

Last updated: March 8, 2026

## 1. Identity of the Data Controller

The application MÉXICO TRAVELSMART.MX ASSISTANT (the "Application") is operated by LHO L&L Holding, S.A. de C.V. (the "Operator"). This policy clearly explains how information is handled within the Application. The Application has been designed under a principle of data minimization and privacy by design, and therefore does not collect or process personal data from users.

## 2. Information We Process

MÉXICO TRAVELSMART.MX ASSISTANT does not collect, transmit, or share personal information from users. The Application does not request or store information such as: name, email address, phone number, location, IP address for identification purposes, device identifiers, contacts, photographs, biometric data, or sensitive information.

The information displayed within the Application corresponds solely to publicly available reference information, such as: embassies, consulates, emergency services, and useful resources for visitors in Mexico.

## 3. Local Storage on Device

The Application stores only two local configuration preferences on the user's device: selected language and audio preference on or off (background music). These preferences are stored exclusively on the user's device, are not transmitted to servers, are not shared with third parties, and do not allow user identification. The purpose of this local storage is solely to improve the user experience of the Application.

## 4. Application Permissions

The Application may use the following system permissions: Internet access (used exclusively to allow the user to open external links to official sites or third-party services) and Network state (used solely to verify whether the device has connectivity before attempting to open external links). The Application does not request or use additional permissions.

## 5. Links to Third-Party Websites

The Application functions as an informational directory providing links to websites operated by independent third parties, such as: embassies, consulates, hospitals, public services, and informational resources for travelers. When the user accesses one of these links, they leave the Application and directly access the corresponding third party's website. The privacy policies of such sites are independent of this Application, and the Operator has no control over their privacy practices or data processing. Users are advised to review the privacy policies of each external site they visit.

## 6. Information Security

Since the Application does not collect or store personal data, it does not maintain user databases or user profiles. Local preferences stored on the device remain solely on the user's own device.

## 7. Privacy Rights

Since the Application does not collect or process personal data, it is generally not necessary to exercise rights of access, rectification, cancellation, or opposition regarding personal information. If a user has any privacy-related concern about the Application, they may contact the Operator.

## 8. Changes to This Policy

This Privacy Policy may be updated occasionally to reflect improvements to the Application or regulatory changes. The current version will always be the one published on the official website.
